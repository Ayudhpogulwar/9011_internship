Section B – Generative AI & LLM Concepts

11. What does LLM stand for?
Answer: Large Language Model.

12. What is Generative AI?
Answer: Generative AI creates new content, such as text, images, audio, and videos.

13. What is a prompt in Generative AI?
Answer: A prompt is an instruction or question given to an AI model.

14. What is a system prompt?
Answer: A system prompt gives the AI its basic instructions, role, and behaviour.

15. What is an AI hallucination?
Answer: An AI hallucination occurs when AI generates incorrect or made-up information as if it were true.

16. What is a token in an LLM?
Answer: A token is a small unit of text that an AI model processes.

17. What does context window mean?
Answer: A context window is the amount of information an AI model can process at one time.

18. What is inference in AI?
Answer: Inference is the process of using a trained AI model to generate an answer or prediction.

19. What is fine-tuning?
Answer: Fine-tuning means further training a pretrained AI model on specific data to improve its performance.

20. What does multimodal AI mean?
Answer: Multimodal AI can understand or generate different types of content, such as text, images, audio, and video.

Section C – Agents, RAG & Modern AI Development

21. What is an AI agent?
Answer: An AI agent can understand a goal, plan steps, use tools, and perform tasks with some independence.

22. What is the main difference between a chatbot and an AI agent?
Answer: A chatbot mainly responds to messages, while an AI agent can also use tools and perform actions to complete tasks.

23. What does RAG stand for?
Answer: Retrieval-Augmented Generation.

24. Why is RAG used with LLMs?
Answer: RAG helps an LLM answer questions using relevant external information.

25. What is an embedding?
Answer: An embedding is a numerical representation of data that helps AI identify similarities in meaning.

26. What is a vector database used for in AI applications?
Answer: It stores and searches numerical vectors to find information with similar meanings.

27. What does tool calling allow an AI model to do?
Answer: Tool calling allows an AI model to request actions from external tools, APIs, or software functions.

28. What does MCP stand for in modern AI application development?
Answer: Model Context Protocol.

29. What is an API key used for?
Answer: An API key is used to identify and authenticate an application when accessing an API.

30. What is meant by an agentic workflow?
Answer: An agentic workflow is a process in which AI plans and performs multiple steps to achieve a goal.
